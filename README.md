## Replication at a glance

1. **Start with student and dyad records.** The pseudonymized inputs include one row per child in `students.csv` and one row per directed game decision in `dyads.csv`. The dyad file records who sent tokens to whom and how the sender nominated the partner in the peer survey.
2. **Build the analysis datasets.** The preparation script matches each decision with the partner's decision in the same round to compute the Cooperation GAP. It classifies dyads from friendship nominations and computes Social Rank within each classroom from popularity nominations. It writes the enriched student and dyad files to `data/generated/`, including filtered transfers in the dyad file. [Data preparation script](code/01_build_measures.R)
3. **Reproduce the results.** The R scripts use those datasets to fit the models, run the Supporting Information checks, and write tables and figures. The notebooks present the same analyses step by step.

### Data and measures

The two study CSVs contain pseudonymized records. The first script builds `analysis_students.csv` and `analysis_dyads.csv`. S4 writes `alternative_ranks.csv` for S8, and S9 writes `behavioral_rank.csv`. This test copy includes all four [generated files](data/generated/), which the scripts rebuild when run.

- **Cooperation GAP** is the number of tokens received from the partner minus the number sent.
- **Friendship type** is mutual friendship, one-sided friendship (sender declares or receiver declares), or non-friendship, based on best-friend nominations.
- **Social Rank** is classroom-specific PageRank on the weighted popularity network, with damping 0.85, rescaled to range from 0 to 1.
- **Social Rank GAP** is the sender’s Social Rank minus the receiver’s.
- **Null-model filter** ranks transfers by their standardized departure from the sender’s usual giving. The top 50% are retained, and a pair enters the filtered analysis when both directions are retained.

The regressions use `lfe::felm()`. The [codebook](data/codebook.md) defines the input variables and generated measures.

## Main workflows

### Clone and reproduce

Clone this repository.

```sh
git clone https://github.com/melanieoyarzun/patio-en-red.git
cd patio-en-red
```

Install [R](https://cran.r-project.org/) (4.3 or later). In the R console, install the analysis dependencies.

```r
install.packages(c("tidyverse", "here", "igraph", "lfe", "ggraph",
                   "patchwork", "scales"))
```

#### Run the R scripts

Run the command for the results you want from the repository root. Both commands start from `data/raw/` and rebuild the required files in `data/generated/`.

| Workflow | Command | Outputs |
|---|---|---|
| Main results | `Rscript code/run_all.R main` | Table 1, Figures 1D, 2, and 3, and numbers cited in the main text. See `output/tables/` and `output/figures/`. |
| Main results and Supporting Information | `Rscript code/run_all.R` | The main results plus SI sections S1–S9. See `output/tables/si/` and `output/figures/si/` for the SI files. |

The formatted Table 1 is `output/tables/table1_display.csv`. To run individual scripts, first run `Rscript code/01_build_measures.R`. Run `code/si/S4_social_rank.R` before `code/si/S8_robustness.R` to generate the alternative Social Rank measures used in S8.

#### Run the notebooks

For Jupyter, install [JupyterLab](https://jupyter.org/install) and the [R kernel](https://irkernel.github.io/). Start JupyterLab from the repository root and run the notebooks in the [documented order](notebooks/README.md#running-the-notebooks). For Quarto, install the build dependencies below and run `quarto render notebooks` to execute the analyses and build the viewer.

### Build the notebook viewer and Jupyter files

To regenerate these materials locally, install [Quarto](https://quarto.org/) (1.6 or later). In the R console, install the additional build dependencies.

```r
install.packages(c("knitr", "rmarkdown", "jsonlite"))
```

| Build | Command | Where to find it |
|---|---|---|
| Local website and notebook viewer | `quarto preview notebooks` | Quarto opens the site in your browser. |
| Static website | `quarto render notebooks` | Open `notebooks/_site/index.html` in a browser. |
| Jupyter notebooks | `quarto render notebooks --profile ipynb --to ipynb` | Open the `.ipynb` files beside their `.qmd` sources. |

Run these commands from the repository root.
